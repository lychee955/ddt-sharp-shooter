# DDT Sharp Shooter

<img src="assets/logo.ico" width="48"/>

这是一个 DDT 工具。基本原理在于，基于广为流传的力度表和简单运动模型[拟合](https://www.52pojie.cn/thread-1132459-1-1.html)出关键参数，得出由风力、角度、距离计算发射力度的一般函数，最后利用 [Pynput](https://github.com/moses-palmer/pynput) 自动发射。

其中，力度通过按压时长来体现，具体见[这里](https://github.com/boring-plans/ddt-sharp-shooter/tree/master)。

## 运行

~~[Releases](https://github.com/boring-plans/ddt-sharp-shooter/releases) 中提供了一些可执行文件，当然你也~~可以在具备 `[uv](https://docs.astral.sh/uv/)` 的环境中，依次执行：

```shell
uv sync
uv run ./main.py
```

来启动。

### 打包

当然，项目根目录提供了一个可用于 `PyInstaller` 打包的 `dss.spec` 文件，为了维护宇宙和平，暂不直接提供可执行文件。

## Getting Started

### 自动分析（默认模式）

启动后会显示小地图预览和多人力度表。自动分析只显示计算结果；只有你通过 `ss` 弹框明确确认力度后才会发射。

1. 按住顶部瞄准图标，将鼠标拖到 36 大厅中的游戏画面内，再松开鼠标，即可自动绑定完整游戏画面。也可将鼠标放到游戏内，按一次 `r` 绑定。无需先按 `tt`，无需手动标记两个角。成功后显示“已绑定游戏窗口”，保存配置并恢复自动分析。
   程序直接读取大厅中 Flash 游戏子窗口的范围，排除标题栏、工具栏和下方力度表。窗口移动、游戏画面缩放后截图区域自动跟随；窗口关闭、重开或游戏控件重载后，请重新拖动绑定。拖到辅助程序、工具栏、力度表或未识别的窗口时，绑定失败并保留原配置，不会把整个大厅误当游戏。拖动中按 `Esc` 取消并恢复之前的监听状态。
   旧的区域配置仍可使用；拖动绑定一次即可升级为自动获取游戏范围。遇到其他登录器、没有独立 Flash 子窗口的布局，或需要自定义截取范围时，可选用“精细校准”，按提示点击左上角、右下角；该方式在客户区大小改变后仍需重新校准。
2. 保持小地图、风力和角度不被辅助窗口遮挡。程序约每半秒检查一次“轮到你出手啦”的提示，提示出现后计算一次。自己的出手期间，通过可用的金色 `PASS` 控件确认回合仍在进行，并检查角度和自己的小地图位置；角度变化，或位置移动至少约 2 个标准小地图像素，连续两次观测稳定后重算。没有变化就保留本轮结果，不重新读取风力、标尺或求解力度。回合结束后停止参数检查，等待下次出手；同一个提示持续显示或短暂闪烁不会重复计算。
   `t` 或“计算一次”按钮可随时手动执行一次计算。计算过程中再次按 `t` 不会堆积任务。若没有找到蓝圈且缓存位置无法确认，会重新截图，最多尝试 5 次；一旦成功就停止。角度、风力、区域错误不会盲目重复计算，会显示原因。
3. 程序用蓝色光圈确定自己，读取自己的圆点主体颜色，再区分队友、敌人。圆点颜色无需固定，每轮重新判断；颜色过于接近时显示“身份不确定”。
   光圈动画暂时消失时，直接使用上次由蓝圈确认的缓存位置，不预测位置，也不按附近圆点的位置逐步移动缓存。必须在缓存位置附近找到唯一圆点，并且地图背景没有明显变化；敌我颜色仍按当前帧重判。只要圆点可靠可见，缓存没有固定的 3 秒期限。蓝圈重新出现时更新缓存；圆点持续丢失超过 2 秒、地图变化、暂停、切换模式或重新标记区域后需要重新确认。
4. 表格列出自己以及其他可见人物的方向、水平距离、高低差和建议力度，编号对应小地图预览。“身份不确定”的人物也按其位置计算力度，身份标签继续保留；只有自己不计算力度。编号仅代表当前帧，不是游戏昵称或固定玩家身份。
   当蓝圈识别失败、但表格已有可见人物时，可点击“编号”左侧“我”列的方框，手动指定其中一个人物为自己。同一时间只勾选一个；点击其他人物可切换，点击已勾选的自己可取消并恢复蓝圈识别。勾选后立即按当前显示的完整截图重算风力、角度、敌我身份、距离和力度，无需重新捕获游戏画面；时间仍显示原截图时间，按 `t` 可刷新。
   手动选择按小地图位置保持，后续刷新和窗口缩放不依赖变化的编号。人物明显移动、消失或重叠时会停止计算并提示重新勾选；地图明显变化、暂停、切换模式或重新绑定会清除选择。手动指定自己仍需有效的风力、角度和标尺，也只显示力度，不自动发射。
5. 力度按计算时的仰角计算。向左的目标需要你手动朝左，向右的目标需要手动朝右；本轮调整角度、改变位置会自动重算，`t` 可立即手动重算。仅风力、道具或其他人物位置改变时也请按 `t`。位置变化必须由重新可见的蓝圈确认，不预测蓝圈位置。超过 100 显示“当前角度力度不足”，没有有效轨迹解则显示原因。
6. 点击“暂停监听”或按 `Esc` 停止自动触发并取消当前重试；暂停保留带时间的最后结果。`t` 可在暂停时计算一次，“开始监听”恢复自动触发。若程序启动时出手提示已经消失，使用 `t` 计算本次出手。

找不到蓝圈、蓝圈不唯一、标尺或参数识别失败时，本轮力度会清空。遮挡、重叠的圆点可能无法分离；无法可靠识别时可切换到原有发射模式手动标记。不同地图、武器特效、障碍物及游戏物理差异可能影响命中。

首版出手触发和持续检查采用截图中的文字提示及金色 `PASS` 模板，支持按游戏宽度缩放。不同版本的字体、提示动画、遮挡或过短的提示可能漏检，此时按 `t` 手动计算。参数检查暂时识别失败时保留已成功计算的结果；同一个变化若计算失败，不反复触发，按 `t` 可重试。人物重试每次使用新的截图；自动分析和手动单次计算均只显示结果，不发送发射按键。

右侧“风力截取”和“角度截取”显示程序实际读取的画面。风力预览应包含完整风向箭头和数字，角度预览应包含左下角的角度数字。如果是地图、空白或缺了一部分，请先完整显示游戏四边，再拖动图标重新绑定；特殊布局可选用“精细校准”。

小地图截取包含右上角地图的完整左右边缘，兼容较宽的地图布局。距离标尺识别使用地图中的视野矩形，避免把整个地图外框宽度当成标尺；预览与人物识别使用同一张完整截取。

拖动绑定通过 Windows `WindowFromPoint` 查找鼠标下的窗口，枚举其中的 Flash 游戏子窗口，使用 `GetClientRect` / `ClientToScreen` 取得实际游戏范围。保存大厅和游戏子窗口的身份，每次截图重新读取范围，从而跟随移动和缩放；身份改变、最小化或游戏画面超出客户区时停止读取并提示原因。人物识别与角度、风力的截取继续按游戏宽度归一化，人物位置来自小地图，避免主画面镜头滚动造成距离错误。

### 双击 s 指定力度发射

在两种模式下均可于半秒内连按两次 `s`，弹出“指定力度发射”。输入例如 `64.25`，按 Enter 或点击“发射”：程序关闭弹框、切回已绑定的游戏窗口，并按指定力度的蓄力时间发射。无需切换模式，多人计算结果保留。请先在游戏里调整方向、角度及道具；该快捷键只控制力度。

力度范围为大于 0、最大 100，支持小数。无效输入留在弹框中提示原因；Esc、取消按钮和窗口关闭按钮都可取消弹框。发射途中重复按 `ss` 不会堆积发射任务；窗口关闭、绑定失效或焦点恢复失败时不发送空格。Esc 可取消尚未开始的发射；蓄力中按 Esc 会松开空格，游戏可能随即以当时力度发射。蓄力计时沿用项目的每力度 0.04 秒，指定力度发射会去掉按键库默认的额外等待；实际力度仍受游戏计时和系统延迟影响。

### 原有发射模式

下面的发射功能需要先在窗口顶部选择“原有发射模式”。切换到默认分析模式时会取消待发射任务；分析模式的 `t` 不会开火。

### 手动档

拟合出的公式大致定义是 `力度=f(风速, x方向距离, y方向距离, 角度)`，故需要约定输入以获取必要参数值。

两次按下 `t` 键后，进入输入状态，而后输入形如 `x12,w-2,d65` 的一段字符串再次按下 `t` 后，会按照：

```
dx=12
dy=0
wind=-2
degree=65
```

的参数赋值计算出所需要的力度，然后发射。其中：

- 参数输入不要求顺序
- 参数默认皆为 0
- 参数的标记需按照约定（即 x, y, w, d）
- 输入过程中按下 `esc` 可退出输入模式（以便快速重新输入以及新的对局清理数据）

注意：现有键盘交互中 `y` 保留为敌我标记快捷键，不能直接输入字符串高度参数；有高低差时请使用小地图标记模式。使用小写字母和英文输入。

### 手动标记后发射

除了直接接收一系列数值，程序也基于 `[ddddocr](https://github.com/sml2h3/ddddocr)` 等库实现了自动识别风力、角度、十屏像素值功能。在进入输入状态后，将鼠标**先放在自己、再放在敌人**的小地图位置上，并分别按下 `y` 即可记录坐标，再按下 `t` 即可触发自动识别、计算、开火。

此功能依赖于游戏区域坐标。两种模式下都可拖动瞄准图标，或将鼠标放到游戏内按 `r`，自动绑定游戏画面；无需先进入输入状态。绑定完成后，手动发射仍需通过 `tt` 开启输入。

### 力度模式

另外，直接输入 `l + 数值`（e.g. l30），可以指定特定力度，而后直接发射。这个模式在 25 级前，有力度提示阶段，非常有用。
